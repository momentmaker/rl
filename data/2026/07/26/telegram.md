🎲 *Random Learning — 2026-07-26*

Three rabbit holes, one theme: what breaks isn't the clever part, it's the plumbing nobody profiles.

*1. Where tokenization bites, and whether byte-level models fix it*
The reframe worth keeping: the strawberry test is not an intelligence failure. "This failure happens before the model even runs. The model never sees s-t-r-a-w-b-e-r-r-y. The tokenizer hands it 1 or 2 atomic ids, so 'how many r's' becomes a memorization question about token #47382." The failure engineers should care about is code, and it's measured: TokDrift tested 9 code LLMs (including 30B+) and found *up to 60% of outputs change under a single semantics-preserving rewrite* — reindent a file or rename a variable and behavior moves, because subword segmentation is learned from statistics, not grammar. The second bill is multilingual and arrives as an invoice: vocabulary size is a RAM/bandwidth decision, so edge models ship compact vocabularies and "live with fragmentation outside their priority languages" — one support-agent bill tripled when two cohorts grew 8x at ~1.6x per-character cost. Byte-level is credible now but not free: BLT hits Llama-3-comparable quality with entropy-segmented patches of 6-8 bytes vs 4.4, up to 50% inference FLOP savings, 30-50% less degradation under noise. New pathology: byte models emitting ill-formed UTF-8. The realistic move is in-place surgery — expand, distill, adapt, or accelerate the tokenizer you already shipped.

*2. What agent memory people actually keep between sessions*
The loudest practitioner post of the month is a defection: "I reverse-engineered the three biggest agent-memory tools. Then I went back to markdown files and LLM wikis over Obsidian." Meanwhile mem0 sits at 62K stars amid a dense run of Show HN memory launches. Best framing is compression, not accumulation — one paper title carries it, *Remember the Decision, Not the Description*: keep goal, next action, and minimum proof hot; push raw traces to an event log referenced by id; set expiry per fact category *before* building extraction. The real failure mode isn't forgetting, it's stale facts with no provenance promoted to ground truth — hence a launch pitched as "agent memory keeping third-party claims from becoming facts." Benchmark correction: LoCoMo doesn't score knowledge updates, and models near-perfect on it drop to 40-60% on MemoryArena. It tests "did the agent recall the right thing," not "should the agent trust what it recalled." The shipped answer in coding agents is a file, and the lesson is the split: persistent memory in MEMORY.md so agent-authored notes never mix into your hand-written rules. Four pricing or hosting changes landed in this one window, which makes portable text files look like a hedge.

*3. Terminal demos as build artifacts*
A demo GIF is stopping being a recording and becoming a build artifact. vhs-action rerenders tapes in CI, so documentation drift becomes a failing build; a Zig git TUI shipped this month documents it in one line — "the gif tapes under docs/assets/ regenerate with vhs; run demo-repos.sh first to set up the scratch repositories they record against." That fixture script is the tell: it's a test with a rendered output, not a video shoot. Decision rule short enough to memorize: VHS for scripted reproducible demos (one .tape → GIF/MP4/PNG, identical every run), asciinema for lightweight copy-pasteable .cast plus agg for GIF, OBS when mouse scrolling in tmux matters. What makes a GIF worth shipping is a checklist, not taste: one outcome, clean start and end, readable text, seamless loop, small file, alt text. The unadvertised inversion is recordings flowing *into* agents — "you throw a screen recording at it and the agent sees what you can't explain in words" — plus agents generating annotated screenshots and terminal GIFs, pixel-verifying each artifact before saving. Funniest signal: r/commandline's satire thread (1,981 upvotes) roasting this genre's README voice, with a one-word top verdict: "CLAUDE.md."
